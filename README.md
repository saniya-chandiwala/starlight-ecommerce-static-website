# Starlight : E-Commerce Jewellery Website

A multi-page responsive frontend storefront for **Starlight**, a fine jewellery e-commerce brand, built using semantic HTML5, custom CSS3, and vanilla JavaScript.

## Features

- **Product Catalog Pages:** Dedicated collection views for Rings, Necklaces, Earrings, and Bracelets (`rings.html`, `necklaces.html`, `earrings.html`, `bracelets.html`).
- **Shopping Cart & Checkout Flow:** Interactive cart management (`cart.html`) and payment interface (`payment.html`).
- **User Authentication & Brand Pages:** Login (`login.html`), Sign Up (`signup.html`), About (`about.html`), and Contact (`contact.html`) pages.
- **Modular Layout Components:** Reusable navigation bar (`navbar.html`) and footer (`footer.html`) loaded dynamically via JavaScript.

## How to Run Locally

1. Clone or download the repository.
2. Open `index.html` with **VS Code Live Server** (recommended so `navbar.html` and `footer.html` load properly via `fetch`) or any local web server.
